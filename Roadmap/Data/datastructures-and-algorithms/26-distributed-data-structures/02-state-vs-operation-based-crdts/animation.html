State-based vs Operation-based CRDTs

Both replicas run a counter and the channel is hostile: it reorders and duplicates messages. A state-based CRDT merges whole states by a join (idempotent) and shrugs it off. A naive operation-based counter applies each delivered op — so a duplicate increment double-counts.
