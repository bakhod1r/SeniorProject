Merge Sort Tree

A segment tree whose every node stores the sorted list of its range (built like merge sort). A range query countLE(l, r, k) decomposes [l,r] into O(log n) canonical nodes and binary-searches "count ≤ k" in each, summing the results — O(log² n).

Operation log

Merge sort tree answers invertible-and-order range queries (count ≤ k, count in band, k-th smallest). Range band = countLE(r,b) − countLE(l−1...,a−1). It is static: one update would re-sort O(log n) lists touching O(n) elements. For updates use sqrt decomposition; for tight memory use a wavelet tree; for O(log n) k-th smallest use a persistent segment tree.
