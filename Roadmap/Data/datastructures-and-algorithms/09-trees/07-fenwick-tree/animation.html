Fenwick Tree (Binary Indexed Tree)

Peter Fenwick 1994. Prefix sums under point updates in O(log n), half the memory of a segment tree, ~6 lines of code each for update/query. The magic: i & -i isolates the lowest set bit.

BIT (binary indexed tree)

Trace

Click update or prefix to walk the BIT. lowbit(i) = i & -i isolates the lowest set bit; update goes i += lowbit(i) upward, prefix goes i -= lowbit(i) downward.

BIT supports invertible aggregates (sum, XOR, count). Range sum = prefix(r) − prefix(l−1). Range update + range query needs two BITs. Beats segment tree on cache/locality at the cost of being limited to invertible operations.
