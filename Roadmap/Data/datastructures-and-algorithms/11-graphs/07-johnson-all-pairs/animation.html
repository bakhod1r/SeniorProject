The Pipeline

1. Bellman-Ford from virtual super-source q → potentials h(v)
2. Reweight:
w'(u,v)=w+h(u)-h(v) ≥ 0
3. Dijkstra from every source on w'
4. Un-reweight:
δ=δ'-h(s)+h(v)

Negative Cycle

If Bellman-Ford still relaxes on pass V, a negative cycle exists and Johnson's rejects the input.
