The Map of Complexity Classes

P — solvable in poly time NP — verifiable in poly time NP-complete (NP's hard rim) co-NP PSPACE / EXP
The open question. Every problem in P is also in NP (if you can solve it fast, you can certainly check it fast), so P ⊆ NP. Whether the reverse holds — P = NP? — is unsolved. No one has found a polynomial-time algorithm for any NP-complete problem, and no one has proven that none exists. The dashed line above marks exactly this unknown boundary: if it collapses, P = NP and the FIND/VERIFY gap disappears.
