Operation Log

Reads check the memtable, then SSTables newest→oldest; each SSTable's bloom filter is consulted first (maybe = read its block, no = skip). A tombstone shadows older values. Compaction merges SSTables, keeps newest values, drops tombstones — reclaiming space.
