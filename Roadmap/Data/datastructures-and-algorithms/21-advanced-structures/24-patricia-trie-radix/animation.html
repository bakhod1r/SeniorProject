PATRICIA Trie / Radix Tree

A trie with single-child chains compressed into string-labeled edges. Insert splits an edge where keys diverge; longest-prefix match (LPM) descends to the deepest matching stored key — the operation behind IP routing.

Canonical use: longest-prefix match for IP routing (Linux kernel fib_trie, BSD radix). Also: in-memory DB indexes (Adaptive Radix Tree in DuckDB / HyPer), HTTP routers (Go httprouter, chi), and Ethereum's Merkle-Patricia trie. Builds on the plain trie (09-trees/05-trie).
