Operation Log

Counter mode: both threads run for { old=load(); if CAS(old, old+1) break }. Only one CAS per contested value can succeed; the loser re-reads the new value and retries — no increment is ever lost. ABA mode: Thread B changes the value A→B→A while Thread A is paused mid-loop; A's CAS then wrongly succeeds because the value looks unchanged. A version tag makes every change unique, so A's stale CAS fails as it should.
