How It Works

The key map points at nodes. Nodes are grouped into frequency buckets: bucket f holds every key used f times, ordered newest→oldest. A use (get/put) promotes a node to bucket f+1. Eviction removes the oldest node in the minFreq bucket — least frequent, oldest on a tie.
