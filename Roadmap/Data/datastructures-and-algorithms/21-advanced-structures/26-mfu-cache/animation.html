MFU Cache Visualization

Key Map + Frequency Buckets (DLLs) + maxFreq | a use promotes a node to the next bucket; eviction removes the oldest node in the maxFreq bucket

LFU evicts the coldest (the least-frequently-used key) — MFU evicts the hottest (the most-frequently-used key). MFU bets that once a key is heavily used it is "done", so the highest-frequency bucket is the eviction target. Ties in that bucket are broken by LRU (the oldest node goes first).

How It Works

The key map points at nodes. Nodes are grouped into frequency buckets: bucket f holds every key used f times, ordered newest→oldest. A use (get/put) promotes a node to bucket f+1. Eviction removes the oldest node in the maxFreq bucket — most frequent, oldest on a tie.
