Path copying: each update clones only the O(log n) nodes on the root-to-leaf path (green) and shares every other subtree by pointer (blue). Old versions stay queryable forever. Second mode walks two versions to find the k-th smallest in a range.

This count tree is built over the value axis: version i is the histogram of the first i elements. k-th descent uses leftCount = version[r].left.cnt − version[l−1].left.cnt to choose a half. Compare with merge-sort tree (O(log²n)), wavelet tree (compact, O(log σ)), and Mo's algorithm (offline).
