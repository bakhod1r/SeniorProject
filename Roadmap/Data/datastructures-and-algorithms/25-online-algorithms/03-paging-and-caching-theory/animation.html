Three Caches, One Stream

LRU evicts the least recently used page. FIFO evicts the oldest inserted page (insertion order, ignores reuse). OPT (Belady) evicts the page whose next use is farthest in the future (or never used again) — provably optimal, but it must see the whole future, so it is an offline-only baseline.
