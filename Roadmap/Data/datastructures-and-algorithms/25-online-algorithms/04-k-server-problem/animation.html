Two Online Strategies, One Request Stream

GREEDY moves the single nearest server to each request. Simple, but on a line it can be driven to unbounded cost. DOUBLE COVERAGE (DC): if the request lies between two servers, move both neighbours toward it at equal speed until one arrives; if the request is outside all servers, move the single nearest. OPT is the offline optimum total movement, computed by dynamic programming over server configurations — the benchmark every online cost is measured against.

Total Movement & Competitive Ratios

Paging is k-server on a uniform metric. If every point is at distance 1 from every other, a cache of size k holding k pages is exactly k servers, and a page fault is a request to a point with no server on it. The line metric here is the harder, geometric cousin where Double Coverage shines.
